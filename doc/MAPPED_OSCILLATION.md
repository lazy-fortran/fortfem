# Local source oscillation on isoparametric triangles

`equilibrated_flux_2d` uses the reference-cell projection
`Pi f = Pi_k(det DF f)/det DF`. Thus `g = f - Pi f` has zero integral on
one physical cell K in exact arithmetic. Previously every non-affine cell
used the global Friedrichs constant for `||g||_K`. This can dominate the
energy error even when the reconstructed flux is accurate.

Let F map the reference triangle to K, F0 map it to the straight vertex
triangle T0, and G = F composed with inverse(F0). Assume the usual conforming,
injective isoparametric cell map. Set

```
L >= sup_Khat ||DF (DF0)^(-1)||_2,
0 < dmin <= det DF,
rhat = det DF f - Pi_k(det DF f),
osc_local = diameter(T0)/pi * L / sqrt(dmin A_min) * ||rhat||_Khat.
```

Subtract the unweighted mean of `v composed with G` on T0 in
`integral_K g v`. Cauchy--Schwarz, Payne--Weinberger on the convex triangle T0,
and change of variables give

```
|integral_K g v|
 <= ||det DG (g composed with G)||_T0 ||v composed with G - mean||_T0
 <= ||rhat||_Khat / sqrt(det DF0) * diameter(T0)/pi
       * ||grad(v composed with G)||_T0
 <= ||rhat||_Khat * diameter(T0)/pi * L/sqrt(dmin) * ||grad v||_K
 <= osc_local ||A^(1/2) grad v||_K.
```

K need not be convex. The tensor case uses a lower bound on the smallest
eigenvalue for A_min. Integrating the reference residual norm directly avoids
the additional loosening from bounding it by `sqrt(max det DF) ||g||_K`.

For P2/P3 geometry, DF has degree one/two. Its six quadratic Bernstein
controls are obtained from values at vertices and edge midpoints. Convexity
of the spectral norm gives L as the largest norm of a transformed control.
The exact Bernstein product formula yields the 15 quartic controls of det DF;
their minimum bounds it over the entire reference triangle. These local
formulas are generated by `gen_equilibrated_flux_products` with `fortsym.lock`.
Reference basis samples are shared by all cells. The additional cell work is
bounded, allocation-free, and runs in the existing OpenMP cell loop.

Use `min(C_F ||g||_K, osc_local)`. If the determinant hull is not positive,
or the straight vertex triangle is not positively oriented, use the original
global term. Affine cells retain their existing sharper diameter/pi formula
and do not compute the additional reference norm.

This is an exact-arithmetic argument for the bound. Projection/integration,
geometry arithmetic, and extrema evaluation are still floating-point and are
not enclosed: the estimator remains practical, not a numerical certificate.
The curved recovery/manufactured tests cover exact recovery, containment,
efficiency, convergence, and independence of local oscillation from a looser
valid global C_F on the fine mesh. KIN6D's NN1 Solov'ev fixture supplies the
consumer regression for the curved P3 source-oscillation defect.
