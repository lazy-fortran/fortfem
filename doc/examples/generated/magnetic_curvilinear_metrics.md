# magnetic_curvilinear_metrics Example

# Curvilinear magnetic coefficients

This example evaluates the metric-to-coefficient transform used by the
two-dimensional Fourier finite-element formulation of the magnetic paper.
For a block-diagonal right-handed metric \(g\) and scalar reluctivity \(\nu\),
FortFEM generates

\[
\nu_{33}=\frac{g_{33}}{\sqrt{g}}\nu,\qquad
\bar{\nu}^{kl}_{t}=\frac{\sqrt{g}}{g_{33}}g_t^{kl}\nu .
\]

The implementation is generated by FortSym and revision-pinned. Cylindrical
and spherical coordinate curves are compared against the paper's analytical
expressions. CI creates `cylindrical_coefficients_1d.png` and
`spherical_coefficients_1d.png`; generated images are not committed.

Provenance: Albert, Lainer, and Biro, *A 2D Fourier finite element formulation
for magnetostatics in curvilinear coordinates with a symmetry direction*,
especially the covariant reluctivity-density and modified transverse
reluctivity equations.

## Usage

```bash
fpm run --example magnetic_curvilinear_metrics
```

## Source Code

```fortran
program magnetic_curvilinear_metrics
    use fortfem_api, only: &
        scalar_reluctivity_curvilinear_fourier_coefficients
    use fortfem_kinds, only: dp
    use fortplot, only: figure, legend, plot, savefig, title, xlabel, ylabel
    implicit none

    integer, parameter :: point_count = 101
    real(dp), parameter :: pi = acos(-1.0_dp)
    real(dp), parameter :: reluctivity = 1.0_dp
    real(dp), parameter :: spherical_radius = 1.4_dp
    character(*), parameter :: output_directory = &
        "output/example/magnetic_curvilinear_metrics"
    real(dp) :: coordinate(point_count), curl_weight(point_count)
    real(dp) :: first_weight(point_count), second_weight(point_count)
    real(dp) :: mass_tensor(2, 2), metric(3, 3), parameter
    real(dp) :: maximum_error
    integer :: point, status

    call execute_command_line("mkdir -p "//output_directory)

    maximum_error = 0.0_dp
    do point = 1, point_count
        parameter = 0.2_dp + 1.8_dp * real(point - 1, dp) / &
            real(point_count - 1, dp)
        coordinate(point) = parameter
        metric = 0.0_dp
        metric(1, 1) = 1.0_dp
        metric(2, 2) = 1.0_dp
        metric(3, 3) = parameter**2
        call scalar_reluctivity_curvilinear_fourier_coefficients( &
            metric, reluctivity, curl_weight(point), mass_tensor, status)
        if (status /= 0) error stop "cylindrical metric transform failed"
        first_weight(point) = mass_tensor(1, 1)
        maximum_error = max(maximum_error, &
            abs(curl_weight(point) - parameter))
        maximum_error = max(maximum_error, &
            abs(first_weight(point) - 1.0_dp / parameter))
    end do
    if (maximum_error > 3.0e-14_dp) &
        error stop "cylindrical metric oracle failed"
    call figure(figsize=[9.0_dp, 5.5_dp])
    call plot(coordinate, curl_weight, label="curl weight R nu")
    call plot(coordinate, first_weight, label="mass weight nu/R")
    call xlabel("cylindrical radius R")
    call ylabel("coefficient for nu = 1")
    call title("Fourier magnetic coefficients in cylindrical coordinates")
    call legend()
    call savefig(output_directory//"/cylindrical_coefficients_1d.png")

    maximum_error = 0.0_dp
    do point = 1, point_count
        parameter = 0.2_dp + (pi - 0.4_dp) * real(point - 1, dp) / &
            real(point_count - 1, dp)
        coordinate(point) = parameter
        metric = 0.0_dp
        metric(1, 1) = 1.0_dp
        metric(2, 2) = spherical_radius**2
        metric(3, 3) = spherical_radius**2 * sin(parameter)**2
        call scalar_reluctivity_curvilinear_fourier_coefficients( &
            metric, reluctivity, curl_weight(point), mass_tensor, status)
        if (status /= 0) error stop "spherical metric transform failed"
        first_weight(point) = mass_tensor(1, 1)
        second_weight(point) = mass_tensor(2, 2)
        maximum_error = max(maximum_error, &
            abs(curl_weight(point) - sin(parameter)))
        maximum_error = max(maximum_error, &
            abs(first_weight(point) - 1.0_dp / sin(parameter)))
        maximum_error = max(maximum_error, abs( &
            second_weight(point) - &
            1.0_dp / (spherical_radius**2 * sin(parameter))))
    end do
    if (maximum_error > 3.0e-14_dp) &
        error stop "spherical metric oracle failed"
    call figure(figsize=[9.0_dp, 5.5_dp])
    call plot(coordinate, curl_weight, label="curl weight sin(theta)")
    call plot(coordinate, first_weight, label="radial mass weight")
    call plot(coordinate, second_weight, label="angular mass weight")
    call xlabel("inclination theta")
    call ylabel("coefficient for nu = 1")
    call title("Fourier magnetic coefficients in spherical coordinates")
    call legend()
    call savefig(output_directory//"/spherical_coefficients_1d.png")
end program magnetic_curvilinear_metrics
```
