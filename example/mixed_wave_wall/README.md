# Coupled mixed wave and resistive wall

This small structure-preserving example couples a first-order mixed wave port
to a resistive RL wall with implicit midpoint. The first plot shows the
computed wave coordinates, velocity, and wall current; the following plot
shows the magnetic/kinetic energy and accumulated resistive dissipation. The
energy ledger is checked at every step. This is a neutral numerical
foundation, not a plasma-wall model.
