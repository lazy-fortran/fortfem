# Three-dimensional sphere BEM

This example solves the unit-sphere Laplace Dirichlet problem with the P0
Galerkin boundary-element method and compares its capacitance with the exact
value \(4\pi\). It also applies the finest-mesh single-layer operator through
both the dense matrix and the pointer-free hierarchical tree. The same
dense-versus-hierarchical comparison is performed for the complex outgoing
Helmholtz kernel. A retained-tree FortNum GMRES solve is compared with the
dense Galerkin solution and the analytical outgoing radial sphere field.

Generated outputs:

- `sphere_capacitance.png`: Galerkin capacitance convergence;
- `sphere_hierarchical_action.png`: dense and hierarchical operator actions;
- `sphere_helmholtz_hierarchical_action.png`: real and imaginary outgoing
  Helmholtz operator actions;
- `sphere_helmholtz_solve.png`: analytical, dense, and hierarchical outgoing
  fields along a radial line;
- `benchmark.txt`: panel counts, dense and hierarchical solve times, GMRES
  iterations and residual, field and density errors, and interaction counts.

The matrix-free tree follows the geometric acceptance principle of
Barnes and Hut, *Nature* 324 (1986), doi:10.1038/324446a0. Exact Galerkin
self-panel entries are retained; only far clusters satisfying both geometric
separation and a low-frequency \(k a\) criterion use monopoles.
The restarted complex GMRES implementation is owned by FortNum; the cluster
tree and exact self terms are built once and retained across all matvecs.

The plots are generated by FortPlot in CI and are intentionally not committed.
