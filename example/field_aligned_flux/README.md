# Field-aligned anisotropic flux

This manufactured profile evaluates the generated pointwise constitutive
block

\[
\mathbf F=k_\perp\nabla u+(k_\parallel-k_\perp)\mathbf b
(\mathbf b\cdot\nabla u)(\mathbf b),
\]

with a smoothly rotating unit direction and (k_\parallel/k_\perp=100).
It plots the parallel/perpendicular gradient components and the resulting
flux magnitude, while writing the sampled values to CSV.

Outputs:

- `field_aligned_flux_components_1d.png`
- `field_aligned_flux_1d.png`
- `field_aligned_flux.csv`

The constitutive value/JVP/VJP kernels are generated by FortSym; this example
contains no copied downstream-code implementation.
