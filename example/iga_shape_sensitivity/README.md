# Isogeometric shape sensitivity and adjoint optimization

This example differentiates a complete scalar isogeometric state problem,

\[
K(P,w)u=f,\qquad
\mathcal J(P,w)=\tfrac12\lVert u-u_\star\rVert_2^2,
\]

with respect to every NURBS control point \(P\) and rational weight \(w\).
Forward mode propagates one prescribed mesh-motion direction. Reverse mode
uses one sparse adjoint solve and returns the full shape gradient, making its
cost independent of the number of geometry design variables.

The local rational-geometry and H1 element products are generated by FortSym.
The sparse solve uses exact implicit tangent and adjoint equations, so the
production path works with GCC and does not differentiate a third-party
factorization. A complete reassemble-and-refactor central difference is used
only as an independent diagnostic and timing baseline.

Generated gallery artifacts:

- `shape_gradient_2d.png`: original control mesh and an exaggerated descent step;
