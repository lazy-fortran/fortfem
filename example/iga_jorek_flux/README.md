# Structure-preserving JOREK flux subflow

This advanced example evolves the ideal poloidal magnetic-flux subflow

\[
M\dot{\psi}=-A(u)\psi,\qquad A(u)^T=-A(u),
\]

on a cylindrical rational B-spline patch. The fixed-potential flow uses the
Cayley/implicit-midpoint map and retains one sparse factorization for every
time step. It therefore preserves the discrete spline mass norm and is exactly
time reversible, up to the linear-solver tolerance.

The example follows STRUPHY's separation of concerns: a commuting FEEC
discretization in space, a semidiscrete antisymmetric bracket, and geometric
integration of each reversible subflow. A full reduced-MHD integrator must
derive and verify every additional Poisson subflow before composing them with
Strang or higher-order symmetric splitting. Dissipative terms require a
separate contractive step and must not use negative Yoshida substeps.

Run with:

```sh
fpm run --example iga_jorek_flux
```

Generated output under `output/example/iga_jorek_flux/` leads with the
computed initial poloidal flux solution in physical `(R,Z)` coordinates and
black arrows for the reconstructed poloidal field. It also includes the final
flux map, a 1D invariant history, and `benchmark.txt`. Images are generated by
CI and are not committed.
