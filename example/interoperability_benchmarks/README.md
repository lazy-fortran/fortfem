# Independent FEM interoperability benchmarks

This example reads the neutral CSV records produced by the isolated FEniCSx,
FreeFEM, and MFEM jobs and renders accuracy and runner-local timing figures
with Fortplot. It does not bundle third-party software or generated images.

Run it after arranging the downloaded artifacts as
`benchmark-results/{fenicsx,freefem,mfem}/{poisson,ampere}.csv`:

```sh
fpm run --example interoperability_benchmarks -- \
  benchmark-results output/example/interoperability_benchmarks
```

The analytical fields and sources are generated by
`tools/codegen/app/gen_interoperability_oracles.f90`. Timings from GitHub
hosted runners are regression diagnostics only: they are not an authoritative
cross-code speed ranking because the jobs do not share dedicated hardware.
