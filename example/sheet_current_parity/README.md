# Sheet-current representation parity

This physical-first slab gallery fixture compares the same tangential sheet
current in two representations: an explicit surface ledger and a normalized
Gaussian layer.  The first plot is the resolved physical current profile with
independent Gaussian oracle markers.  A JSON/CSV record retains the integrated
ledger and parity error; generated media are ignored by the repository.

This is a geometry-neutral foundation example, not a plasma equilibrium or
Ampere solver.  Cylinder, sphere, and torus surface parametrizations can use
the same contract while supplying their own surface quadrature.
