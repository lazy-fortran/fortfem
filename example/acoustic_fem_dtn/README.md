# Elastic FEM with an acoustic DtN boundary

This example couples complex, time-harmonic P1 elasticity to an outgoing
fluid half-space. FortFEM eliminates the acoustic pressure through the planar
FFT Dirichlet-to-Neumann map and solves the resulting complex system with
FortSparse.

The manufactured longitudinal wave has an independently derived traction
balance at the fluid interface. The program plots the numerical and
analytical centerline displacement and the displacement along the artificial
boundary. The 5 MHz steel-water fixture from `paper_acoustics` revision
`6300ab0` is checked against the discrete plane-wave layer solution.

FortFEM uses the time dependence `exp(-i omega t)`, so a lossy material has
`Im(c) < 0` and `Im(E) < 0`, as in this example.

Generated images are written under
`output/example/acoustic_fem_dtn/`; images are generated by CI and are not
stored in git.
